# Resource reference

Each SzCore feature is independently versioned in its own repository.

## Foundation

- `szcore` — framework runtime and services
- `szcore_ui` — shared UI primitives
- `szcore_interact` — target/third-eye layer
- `szcore_queue` — connection queue
- `szcore_world` — ambient population/world policy

## Character

- `szcore_multichar`
- `szcore_spawn`
- `szcore_appearance`
- `szcore_status`
- `szcore_death`

## Economy / organizations

- `szcore_banking`
- `szcore_billing`
- `szcore_society`
- `szcore_paycheck`

## Inventory

- `szcore_inventory`

## Vehicles

- `szcore_vehicles`
- `szcore_garage`
- `szcore_vehiclekeys`
- `szcore_vehiclefailure`

## Operations

- `szcore_admin`
- `szcore_benchmark`
- `szcore_smallresources`

## Compatibility

- `szcore_compat_esx`
- `szcore_compat_qb`
- `szcore_compat_qbox`

Open the README and `docs/` folder in each repository for its local API, configuration and installation reference.
