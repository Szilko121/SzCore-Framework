# Contributing

Thank you for improving SzCore.

- Open an issue for a reproducible bug or API proposal.
- Keep pull requests focused on one concern.
- Explain database/API compatibility impact.
- Include reproduction steps and validation performed.
- Avoid adding mandatory dependencies to the core when a module can remain optional.
- Do not claim performance gains without before/after measurements on the same environment.

By contributing, you confirm you have the right to submit the code under the repository’s applicable license/contribution terms.
