## 🛠️ Telepítés

A keretrendszer legkönnyebben a [`SzCore-Recipe`](https://github.com/Szilko121/SzCore-Recipe) segítségével telepíthető txAdmin-ban!

```bash
# Git klónozás a szerver resources mappájába:
cd resources/[szcore]
git clone https://github.com/Szilko121/szcore.git
```
